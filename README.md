The goal of this project was to extract, clean, and analyze text from faculty publications—specifically titles and abstracts—to discover dominant research themes across departments such as:
Computer Science
Data Science
Informatics
Mathematical Sciences
Applied Engineering & Technology
Using R, we transformed raw Scopus data into meaningful insights through NLP preprocessing and n-gram modeling.
🛠️ Technologies Used
R / RStudio
tidyverse
tidytext
readr, dplyr, stringr
ggplot2 (for visualizations)
Excel (via write_xlsx)
📥 Data Sourcing
Faculty publications were collected from Scopus, where titles and abstracts were exported into a CSV file for analysis.
